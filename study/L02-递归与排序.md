## 1. 递归

### 1.1 定义与两个要素

**递归函数 = 自己调用自己的函数。** 写好它只需要两件事：

1. **基准情形（base case）**：最小规模的问题，直接给答案，不再递归。
2. **递推关系（recursive case）**：把规模 n 的问题化成**规模更小**的同类问题。

漏掉第 1 条 → 无限递归 → 栈溢出（`Segmentation fault`）。
递推没有向基准收敛 → 同样栈溢出。

```c

}
```

### 1.2 递归法一：直接照着递推式写

直接翻译数学定义。**问题在于"一次只要一项"**：算 `F(n)` 要算 `F(n-1)` 和 `F(n-2)`，而这两个又各自把下面的项重算一遍。同一子问题被反复计算，工作量指数爆炸。

**写完后你必须自己回答**：画出 `n = 5` 的递归调用树，数一数 `F(1)` 被算了多少次？`F(0)` 呢？

### 1.3 递归法二：递归对（把两项打包成一个状态）

前一种写法的问题在于"一次只要一项"。**把两项打包成一个状态**：

$$G(n) = \bigl(F(n+1),\, F(n)\bigr), \qquad F(n) = G(n)_2$$

于是有递推

$$G(n) = \bigl(F(n+1),\,F(n)\bigr) = \bigl(F(n)+F(n-1),\,F(n)\bigr)$$

如果你已经算出 $G(n-1) = (F(n), F(n-1))$，那么 $G(n)$ 只需要**一次加法**就能从这个状态得到。

> **关键洞察**：把"计算 $F(n)$"变成"沿状态序列走 n 步"，每一步 O(1) 工作 → 总时间 **O(n)**，而不是 O(φⁿ)。
> 这就是"记忆化/动态规划"思想的第一次出场：**不重复计算已经算过的状态**。

**骨架（留白）**：

```c
/* 返回 G(n) = (F(n+1), F(n))，用递归对的方式，时间 O(n) */
static void fib_pair(int n, long long *fn1, long long *fn) {
    /* TODO 基准：n == 0 时 G(0) = (F(1), F(0)) = (1, 0) */
    /* TODO 递推：先求出 G(n-1)，再用它算出 G(n) */
}
```

拿到递归对之后，**再改成迭代**（用两个变量滚动），就得到了 O(n) 时间、O(1) 空间的版本。这一步你自己做。

### 1.4 增长率：φ 从哪来

设 $F(n) \approx c\,r^n$，代入 $F(n) = F(n-1) + F(n-2)$：

$$r^n = r^{n-1} + r^{n-2} \;\Longrightarrow\; r^2 = r + 1 \;\Longrightarrow\; r = \frac{1 \pm \sqrt 5}{2}$$

即 $\varphi = \dfrac{1+\sqrt 5}{2} \approx 1.618034$，$\psi = \dfrac{1-\sqrt 5}{2} \approx -0.618034$。

**所以递归法一的复杂度是 $O(\varphi^n)$**，而 $\varphi^5 \approx 11.09$：**n 每加 5，耗时约乘 11**。

## 2. Fibonacci 数列：封闭式与精度边界

### 2.1 封闭式（Binet 公式）

$$F(n) = \frac{\varphi^n - \psi^n}{\sqrt 5}$$

因为 $|\psi| < 1$，$\psi^n \to 0$，所以 $F(n)$ 是离 $\varphi^n/\sqrt5$ **最近的整数**。于是"特征值法"看起来是 O(1)。

### 2.2 精度边界：O(1) 是要付代价的

课件强调：**"用封闭式把算法变成 O(1)"这句话必须加一个条件**——在双精度还能分辨出整数位之前。

| 事实 | 数值 | 说明 |
|---|---|---|
| 双精度有效位数 | $2^{53} \approx 9.007\times10^{15}$ | 超过之后**连续整数之间无法区分** |
| $F(78)$ | $8944394323791464$ | $< 2^{53}$，双精度仍能精确表示 |
| $F(79)$ | $14472334024676221$ | $> 2^{53}$，双精度**无法逐位精确** |
| `INT64_MAX` | $9223372036854775807$ | |
| $F(92)$ | $7540113804746346429$ | 最大的可精确存放的项 |
| $F(93)$ | $12200160415121876738$ | **溢出 Int64** |

**结论（要写进作业报告）**：

- 想要**精确**的整数结果 → 用整数路线（递推/递归对/矩阵幂 + `long long`），能精确算到 $F(92)$。
- 想要**O(1) 的近似值** → 用封闭式 + `double`，但在 $n \ge 79$ 附近就开始不可信。
- **"复杂度更低"不等于"结果更可用"**——这是本讲最值得记住的一句话。

## 3. 特征值：把递推写成矩阵幂

### 3.1 矩阵法

把状态写成向量，递推写成矩阵乘法：

$$G_n = \begin{pmatrix} F(n+1) \\ F(n)\end{pmatrix}, \qquad G_n = A\,G_{n-1}, \qquad A = \begin{pmatrix} 1 & 1 \\ 1 & 0\end{pmatrix}$$

所以

$$G_n = A^{\,n-1} G_1, \qquad G_1 = \begin{pmatrix} F(1) \\ F(0)\end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

**验证一下**：$A\binom{1}{0} = \binom{1}{1} = \binom{F(2)}{F(1)}$ ✓；$A^2\binom{1}{0} = A\binom{1}{1} = \binom{2}{1} = \binom{F(3)}{F(2)}$ ✓。

**为什么要这样写**：因为矩阵幂可以用**快速幂（平方求幂）** 在 $O(\log n)$ 次矩阵乘法内算出，而每次矩阵乘法是常数时间（2×2）。于是整个算法 $O(\log n)$。

**快速幂骨架（留白，你在作业里写）**：

```c
typedef struct { long long a, b, c, d; } Mat2;   /* [[a,b],[c,d]] */

Mat2 mat_mul(Mat2 x, Mat2 y);      /* TODO 2x2 矩阵乘法，8 次乘法 4 次加法 */
Mat2 mat_pow(Mat2 m, long long n); /* TODO 平方求幂：n 为偶数 / 奇数分别怎么处理？ */
```

**你必须自己回答**：`mat_pow` 的迭代版怎么写？用一个 2×2 单位矩阵当累加器，每次看 n 的最低位。

### 3.2 特征值分解与特征分析法

$A = \begin{pmatrix}1&1\\1&0\end{pmatrix}$ 的特征多项式是 $\det(A - \lambda I) = \lambda^2 - \lambda - 1 = 0$，特征值正是 $\varphi$ 与 $\psi$。

把 $G_1$ 用特征向量展开，$A^n$ 作用在特征向量上就是把特征值取 n 次方，于是直接得到 Binet 公式。**这就是"特征值法"的来历**——它不是另一套技巧，而是矩阵法的解析解。

**一句话串起来**：

```
递推定义 ──→ 递归法一（直接翻译）        O(φⁿ)
         ──→ 递归对（打包状态）          O(n)
         ──→ 矩阵法（A 的幂）            O(log n)
         ──→ 特征值法（解出封闭式）        O(1) 但有精度上限
```

## 4. 排序

### 4.1 三种基本排序（写之前先想清楚"每一轮在做什么"）

| 算法 | 一句话思想 | 每轮结束后保证什么 |
|---|---|---|
| **冒泡** | 相邻两两比较，大的往后换 | 末尾 i 个元素已就位 |
| **插入** | 把第 i 个元素插到前面已排序部分的正确位置 | 前 i 个元素局部有序 |
| **快速** | 选一个基准（pivot），把数组分成"≤基准 / ≥基准"两半，递归处理 | 基准到了最终位置 |

**冒泡的两个优化点（写的时候要做到）**：① 内层循环上界随轮数递减（已就位的不用再看）；② 若某一轮一次交换都没发生，说明已经有序，立即结束。

**快速排序的关键选择**：基准怎么选？最坏情况发生在每次划分极不均匀时（如对**已排好序**的数组取首元素为基准 → 每层只减少 1 个元素 → $O(n^2)$）。**对策：三数取中**（取首、中、尾的中位数）或随机基准。

### 4.2 3-路快速排序（作业二要交，也是重复元素多的正解）

普通快排在**大量重复元素**时会退化：等于基准的元素全被分到一侧，递归深度接近 n。

**3-路划分**把数组分成三段：`< pivot`、`== pivot`、`> pivot`，等于基准的那一段**不再参与递归**。用三个指针（常记作 `lt`、`i`、`gt`）：

```
   [ < pivot | == pivot | 未处理 | > pivot ]
     ^         ^          ^        ^
     lt        i          gt
```

**骨架（留白，你自己补完）**：

```c
static void quick3(int *a, int lo, int hi) {
    if (lo >= hi) return;
    int pivot = a[lo];           /* 你可以在作业里改成三数取中 */
    int lt = lo, i = lo + 1, gt = hi;
    while (i <= gt) {
        if      (a[i] < pivot) { /* TODO 换到 lt 区，lt++ i++ */ }
        else if (a[i] > pivot) { /* TODO 换到 gt 区，gt-- （i 不动！为什么？） */ }
        else                   { /* TODO 留在中间区，i++ */ }
    }
    quick3(a, lo, lt - 1);
    quick3(a, gt + 1, hi);
}
```

> **必须自己想明白的问题**：`a[i] > pivot` 时换过来的元素**还没看过**，所以 `i` 不能加。这个细节错了排序就不对。

### 4.3 复杂度与稳定性对照（作业报告要写）

| 算法 | 最好 | 平均 | 最坏 | 额外空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 插入 | O(n) | O(n²) | O(n²) | O(1) | ✅ |
| 快速 | O(n log n) | O(n log n) | O(n²) | O(log n) 栈 | ❌ |
| 3-路快速 | O(n) | O(n log n) | O(n²) | O(log n) 栈 | ❌ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✅ |

（3-路快排在"全部元素相同"时是 O(n)——只有一趟划分，这是它的最大价值。）

### 4.4 分治

快排与归并都是分治，分治的三步永远一样：

1. **分（divide）**：把问题切成规模更小的同类子问题；
2. **治（conquer）**：递归解决子问题（到基准情形直接给答案）；
3. **合（combine）**：把子问题的解合并成原问题的解。

**快排与归并的区别就在"合"这一步**：快排的"合"是空的（划分完就已经有序），归并的"合"是核心（把两条有序序列并成一条）。**L04 的链表排序会直接用到这个区别。**

## 6. 常见错误（错在哪 → 怎么改 → 为什么）

| 错误 | 症状 | 原因与改法 |
|---|---|---|
| 递归忘记基准情形 | `Segmentation fault` | 先写基准情形，再写递推 |
| 递归法一算 n=50 | 程序跑不完 | 这是 O(φⁿ)，不是 bug；要快就用递归对/矩阵法 |
| `int` 存 Fibonacci | n=47 之后变负数 | `int` 溢出；改用 `long long`（能到 F(92)） |
| 用 `double` 算大 n | 结果最后几位不对 | 超出 $2^{53}$ 无法精确；要精确就用整数路线 |
| 快排对有序数组 | 慢到 O(n²) | 基准取首元素；改成三数取中或随机基准 |
| 3-路划分里 `gt--` 后也 `i++` | 排序结果错 | `gt` 换过来的元素还没看过，`i` 不能加 |
| 矩阵法写成 `A^n` 但初始向量用错 | 结果偏一项 | 核对 $G_n = A^{n-1}G_1$（指数是 n−1，不是 n） |
| 库函数忘了 `extern "C"` 或符号看不到 | Python 加载后找不到函数 | 用 `nm -D lib.so` 确认符号导出；C 编译器不需要 `extern "C"`，C++ 才需要 |
| ctypes 不声明 `argtypes` | 随机崩溃或结果错 | 32/64 位与指针类型必须显式声明 |
