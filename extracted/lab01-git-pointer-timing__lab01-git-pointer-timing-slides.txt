关于 Git
Git 的定义
Git：一种分布式版本控制系统，用于跟踪文件的更改。
版本控制：记录文件随时间的变化，允许回溯到以前的版本。
为什么使用Git？
协作：多个开发者可以同时工作，不会互相干扰。
历史记录：可以查看项目的历史记录，了解每次更改的原因和内容。
分支管理：可以创建分支，独立开发新功能或修复bug，然后合并回主分支。
Git 交友
世界上众多的程序员（可能超过 90%）在使用 git 管理他们的文件，其中很多集中在
Github.com
GitLab.com

Git 的基本概念
工作目录（Working Directory）
定义：你正在进行更改的文件所在的目录。
作用：保存当前项目的状态。
暂存区（Staging Area）
定义：准备提交更改的区域。
作用：允许你在提交前检查和调整更改。
本地仓库（Local Repository）
定义：存储在你计算机上的项目历史记录。
作用：包含所有的提交和分支，是项目的个人记录。
远程仓库（Remote Repository）
定义：托管在网络上的项目版本。
作用：允许多个开发者协作，通过推送和拉取共享资源。

在 Python 里有没有指针？有没有指针的替代品？如何使用？

print(my_list) # 输出: [100, 2, 3, 4, 5]
使用引用：Python 中的变量实际上是对对象的引用
a = [1, 2, 3]

===== PAGE 25 =====
延伸：Python 中的对象与引用
在 Python 中，改变变量的值的行为取决于变量的数据类型。Python 中的变量实际上是对对象的引用，而不是直接存储值。
以下是详细的解释：
不可变数据类型
对于不可变数据类型（如整数、浮点数、字符串和元组），改变变量的值会创建一个新的对象，并将变量引用指向这个新对
象。
示例：
a = 5
print(id(a)) # 输出对象 a 的内存地址
a = 10
print(id(a)) # 输出对象 a 的新内存地址
在这个例子中，a 最初指向值为 5 的对象。当 a 被赋值为 10 时，Python 创建了一个新的对象，并将 a 的引用指向这个新对
象。

===== PAGE 26 =====
延伸：Python 中的对象与引用
可变数据类型
对于可变数据类型（如列表、字典和集合），改变变量的值通常是在原有对象上进行修改，而不会创建新的对象。
示例：
lst = [1, 2, 3]
print(id(lst)) # 输出列表 lst 的内存地址
lst.append(4)
print(id(lst)) # 输出列表 lst 的内存地址，地址不变
在这个例子中，lst 是一个列表。当我们使用 append 方法向列表中添加元素时，列表的内存地址没有改变，说明是在原有
对象上进行的修改。
总结
不可变数据类型：改变值会创建一个新对象，并改变引用。
可变数据类型：改变值通常是在原有对象上进行修改，不会改变引用。
